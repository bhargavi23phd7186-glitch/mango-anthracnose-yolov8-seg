
# Dataset

This directory is intended to organize the data used in the mango anthracnose detection and severity estimation project.

## Structure

- `raw_videos/` – Original orchard videos used for frame extraction.
- `extracted_frames/` – Frames extracted from videos at the specified sampling interval.

## Data access

The original dataset is not included in this repository. Dataset access and availability are subject to the conditions described in the research paper.
