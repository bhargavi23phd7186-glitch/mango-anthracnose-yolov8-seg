
# Extracted Frames

This folder is intended to store the image frames extracted from the original mango orchard videos.

## Extraction Configuration

- Frame sampling interval: Every 15th frame.
- Reference video resolution: 1920 × 1080 pixels.
- Reference frame rate: 58.53 FPS.
- Output image format: PNG.

## Organization

Extracted frames are organized into separate subfolders based on their source video.

## Note

The extracted image dataset is not included in this repository.
