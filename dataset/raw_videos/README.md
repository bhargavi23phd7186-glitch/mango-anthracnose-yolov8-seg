
# Raw Videos

This folder is intended to store the original mango orchard videos used in the research.

## Purpose
The videos serve as the source data for extracting mango leaf images.

## Frame Extraction
- Sampling interval: Every 15th frame.
- Reference resolution: 1920 × 1080 pixels.
- Reference frame rate: 58.53 FPS.

## Note
The original video files are not included in this GitHub repository. They are retained separately as source data.
