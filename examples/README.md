# Example Images and Outputs

This folder is intended to contain example images and visualization outputs from the mango anthracnose detection and severity estimation pipeline using YOLOv8-Seg.

The examples may include:

- Healthy mango leaf images.
- Anthracnose-affected mango leaf images.
- Leaf segmentation outputs.
- Disease lesion segmentation outputs.
- Pixel-wise disease area visualizations.
- Disease severity estimation examples.

These examples are intended to demonstrate the operation of the proposed image-processing and segmentation pipeline.

Only images approved for public sharing will be included.
