# Python Source Code

This folder contains the Python source code for the proposed mango anthracnose detection and disease severity estimation pipeline using YOLOv8-Seg.

The implementation includes the following modules:

1. Image preprocessing and normalization.
2. Mango leaf detection and segmentation.
3. Leaf validation gate.
4. Anthracnose disease segmentation.
5. Pixel-wise disease area calculation.
6. Disease severity percentage estimation.
7. Disease severity classification.

The actual Python implementation files will be organized in this directory to support code accessibility and reproducibility of the reported experiments.
