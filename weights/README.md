# Model Weights

This folder is intended to contain the trained model weights used in the mango anthracnose detection and disease severity estimation pipeline based on YOLOv8-Seg.

The trained YOLOv8n-Seg model weights will be made available here, subject to file-size and distribution requirements.

The model weights are intended for:

- Mango leaf detection and segmentation.
- Anthracnose disease segmentation.
- Disease severity estimation.

## Model Information

- Model architecture: YOLOv8n-Seg
- Framework: Ultralytics YOLO
- Input image size: 640 × 640 pixels

## Usage

The trained model weights can be loaded using the Ultralytics YOLO framework.

The final model weight file and instructions for downloading or accessing it will be provided after verification.
