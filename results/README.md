# Experimental Results

This folder is intended to contain the evaluation results and outputs generated by the mango anthracnose detection and severity estimation pipeline using YOLOv8-Seg.

The results may include:

- Model training and validation metrics.
- Precision, recall and F1-score.
- Detection and segmentation mAP metrics.
- Confusion matrix.
- Receiver Operating Characteristic (ROC) curve.
- Disease severity estimation outputs.
- Segmentation visualization examples.

All reported results will correspond to the verified experimental implementation described in the associated research article.
